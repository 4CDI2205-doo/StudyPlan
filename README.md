# StudyPlan

## 概要
StudyPlanは、日々の学習時間を記録・管理するためのWebアプリケーションです。

学習内容や学習時間を登録し、履歴の確認・編集・削除を行えるほか、学習時間をグラフで可視化することで、自分の学習状況を把握しやすくしています。

---

## 制作目的

毎日の学習を継続しやすくするために、学習時間や進捗を記録できるアプリを制作しました。

PHP・MySQLを用いたWebアプリケーション開発を学ぶことを目的として制作しています。

---

## 主な機能

- ユーザー登録
- ログイン・ログアウト
- 学習履歴の追加
- 学習履歴の一覧表示
- 学習履歴の編集
- 学習履歴の削除
- 今日の学習時間の表示
- 科目ごとの学習時間を円グラフで表示
- 学習履歴の管理

## 工夫した点

- PHPとMySQLを連携し、ユーザーごとに学習履歴を管理
- SQLで学習時間を集計し、グラフへ反映
- Chart.jsを利用して学習状況を可視化
- CSSを用いて見やすいレイアウトを意識

---

## 苦労した点

最も苦労した点は、

- 日ごとの学習時間をSQLで集計する処理
- SQLで取得したデータをJavaScriptへ渡し、円グラフとして表示する処理

です。

エラーが発生した際には原因を調査し、試行錯誤を繰り返しながら解決しました。
